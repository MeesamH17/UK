# Publishing website
Static site: upload every file in this folder to Hostinger `public_html`.

## Edit
- Search all files for `Plotline` (the sample brand name) and `[EDIT` / `[EMAIL` / `[PHONE` / `[STREET` and replace.
- Contact form: set `ENDPOINT` in `js/forms.js` (e.g. Formspree). Until then it does NOT send email.
- Sample books and testimonials are fictional placeholders.
- Page HTML is generated, but you can edit the .html files directly.
- Privacy/Terms pages are not written; add your own and relink the footer.
